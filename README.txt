# 割り勘計算機 v2

SEO・広告導入を想定した公開用バージョンです。

## ファイル
- index.html : メインページ
- privacy.html : プライバシーポリシー
- terms.html : 利用規約
- contact.html : お問い合わせ
- robots.txt : クローラー向け設定
- sitemap.xml : サイトマップ

## 公開前に変更する箇所
1. index.html の canonical / OGP URL を実際のサイトURLへ変更
2. sitemap.xml の URL を実際のサイトURLへ変更
3. privacy.html の内容を実際の広告・解析サービスに合わせて確認
4. contact.html に実際のお問い合わせ先を追加
5. 広告サービス承認後、広告コードを広告枠へ追加

## 注意
AdSense等の広告サービスの審査通過や検索順位、広告収益は保証されません。


## 広告枠について
index.html に広告枠を2か所配置済みです。
- 広告枠①：タイトルの下・計算機の上
- 広告枠②：計算機の下・説明コンテンツの上

現在はプレースホルダー表示です。
AdSense等の審査承認後、広告サービスから発行されたコードを該当箇所へ入れてください。
